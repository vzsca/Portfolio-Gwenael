## Contexte

J'ai développé v-bot comme projet personnel afin de créer mon propre bot Discord et de progresser en Python, en architecture de projet et en développement d'outils pour une communauté.

## Conditions et moyens

Projet individuel développé en Python avec `discord.py`. Le projet est versionné sur GitHub et utilise un fichier `.env` pour les informations sensibles. Le bot comprend notamment des cogs, des commandes préfixées et slash, des logs et un panneau local.

## Description de l'activité

1. Création du bot et mise en place de l'architecture en cogs.
2. Ajout de commandes de modération et d'information.
3. Mise en place de commandes réservées aux propriétaires et d'un système d'arrêt d'urgence.
4. Ajout de fonctionnalités comme le snipe, les logs et les annonces.
5. Développement d'un panneau local pour gérer le bot.
6. Évolution du projet par versions successives et corrections de bugs.

## Productions et preuves

- Dépôt GitHub du projet : <a href="https://github.com/vzsca/v-bot" target="_blank" rel="noopener noreferrer">github.com/vzsca/v-bot</a>.
- Code source Python organisé en cogs.
- Fichier de configuration `.env.example`.
- Panneau local.
- README et historique des versions.

## Ce que j'en retiens

Ce projet m'a permis de mieux comprendre l'organisation d'une application Python qui évolue dans le temps, ainsi que la gestion de configuration et de fonctionnalités séparées dans plusieurs modules.
