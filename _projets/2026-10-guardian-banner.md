## Contexte

J'ai créé Guardian Banner comme projet de modding Minecraft afin d'apprendre à développer une fonctionnalité complète avec Forge et à la publier sous forme de versions successives.

## Conditions et moyens

Projet individuel développé pour Minecraft 1.20.1 avec Forge et Java. Le projet est versionné sur GitHub et utilise GitHub Actions pour automatiser la génération du fichier du mod.

## Description de l'activité

1. Création du mod Forge et de son système de bannière.
2. Mise en place d'une zone d'action autour de la bannière.
3. Ajout d'un système attirant les ennemis dans un rayon défini.
4. Protection de la zone contre les dégâts d'explosion des creepers et autres explosions.
5. Ajout d'une règle empêchant de placer plusieurs bannières principales trop proches.
6. Ajout d'une interface permettant de modifier le comportement du système.
7. Corrections et publication de plusieurs versions du mod.

## Productions et preuves

- Code source du mod.
- Fichier JAR généré par GitHub Actions.
- README du projet.
- Historique des versions et tags.

## Ce que j'en retiens

Ce projet m'a permis de mieux comprendre le cycle de développement d'un mod Minecraft, depuis l'idée et le code jusqu'aux tests, aux corrections et à la génération automatique d'une version distribuable.
